- **Procedure Name:** Initial Registration Not Accepted by the Network

- **Triggering Conditions:**
    - The initial registration request cannot be accepted by the network.
    - General NAS level mobility management congestion control.
    - General NAS level mobility management congestion control for an SNPN providing access for localized services in SNPN.
    - Operator determined barring in NB-N1 mode.
    - Core network redirection for CIoT optimizations.
    - All the S-NSSAI(s) included in the requested NSSAI are rejected.
    - The UE sends the initial registration request along with the authenticated indication over N2 reference point on non-3GPP access and does not receive the indication that authentication by the home network is not required over N12 reference point, or the 5G-RG acting on behalf of an AUN3 device is not allowed to access 5GS.
    - The initial registration request from a UE supporting CAG is rejected due to CAG restrictions.
    - The UE's initial registration request is via a satellite NG-RAN cell and the network is able to determine that the UE is in a location where the network is not allowed to operate.
    - The AMF receives the initial registration request including the service-level device ID set to the CAA-level UAV ID in the Service-level-AA container IE and the AMF determines that the UE is not allowed to use UAS services via 5GS based on the user's subscription data and the operator policy.
    - The UE initiates the registration procedure for disaster roaming services and the AMF determines that it does not support providing disaster roaming services for the determined PLMN with disaster condition to the UE.
    - The AMF receives the initial registration request over non-3GPP access and detects that the N3IWF used by the UE is not compatible with the allowed NSSAI and the UE has indicated its support for slice-based N3IWF selection in the REGISTRATION REQUEST message.
    - The AMF receives the initial registration request over non-3GPP access and detects that the TNGF used by the UE is not compatible with the allowed NSSAI and the UE has indicated its support for slice-based TNGF selection in the REGISTRATION REQUEST message.
    - The AMF received multiple TAIs from the satellite NG-RAN and determines that, by UE subscription and operator's preferences, all of the received TAIs are forbidden for roaming or for regional provision of service.
    - The UE indicates support of the RAT utilization control in the REGISTRATION REQUEST message over 3GPP access, the network decides to apply the RAT utilization control based on the operator policy, and the secure exchange of NAS messages via a NAS signalling connection is established between the UE and the AMF.

- **Steps:**
    1.  The AMF sends a REGISTRATION REJECT message to the UE including an appropriate 5GMM cause value.
    2.  Based on the 5GMM cause value in the REGISTRATION REJECT, the UE takes specific actions as defined in the specification for each cause value.

- **Decision Points:**
    - 5GMM cause value in REGISTRATION REJECT = #3 or #6 → UE sets 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes registration information, considers USIM/entry as invalid.
    - 5GMM cause value in REGISTRATION REJECT = #7 → UE sets 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes registration information, considers USIM/entry as invalid.
    - 5GMM cause value in REGISTRATION REJECT = #10 → UE aborts the initial registration procedure.
    - 5GMM cause value in REGISTRATION REJECT = #11 → UE sets 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes registration information, stores the PLMN identity in the forbidden PLMN list.
    - 5GMM cause value in REGISTRATION REJECT = #12 → UE sets 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes TAI related information, enters 5GMM-DEREGISTERED.LIMITED-SERVICE.
    - 5GMM cause value in REGISTRATION REJECT = #13 → UE sets 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes TAI and registration information, enters 5GMM-DEREGISTERED.LIMITED-SERVICE or 5GMM-DEREGISTERED.PLMN-SEARCH.
    - 5GMM cause value in REGISTRATION REJECT = #15 → UE sets 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes TAI and registration information, stores current TAI, enters 5GMM-DEREGISTERED.LIMITED-SERVICE.
    - 5GMM cause value in REGISTRATION REJECT = #22 → T3346 value IE is present and not zero/deactivated → UE aborts initial registration, enters 5GMM-DEREGISTERED.ATTEMPTING-REGISTRATION, starts T3346. / Otherwise, abnormal case.
    - 5GMM cause value in REGISTRATION REJECT = #27 → UE sets 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes registration information, disables N1 mode capability, enters 5GMM-DEREGISTERED.LIMITED-SERVICE.
    - 5GMM cause value in REGISTRATION REJECT = #31 → UE enables E-UTRA capability, disables the N1 mode capability for 3GPP access, and enter the 5GMM-DEREGISTERED.NO-CELL-AVAILABLE
    - 5GMM cause value in REGISTRATION REJECT = #36 → UE sets 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes registration information, stores the PLMN identity in the forbidden PLMN list, enters state 5GMM-DEREGISTERED.PLMN-SEARCH
    - 5GMM cause value in REGISTRATION REJECT = #62 → UE aborts initial registration, enters 5GMM-DEREGISTERED. ATTEMPTING-REGISTRATION or 5GMM-DEREGISTERED.PLMN-SEARCH, resets the registration attempt counter and takes actions based on the rejection cause in the rejected S-NSSAI(s).
    - 5GMM cause value in REGISTRATION REJECT = #72 → UE sets the 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes last visited registered TAI and TAI list. If the UE is not registering or has not registered to the same PLMN over 3GPP access, the UE shall additionally delete 5G-GUTI and ngKSI. Additionally, the UE shall reset the registration attempt counter and enter the state 5GMM-DEREGISTERED.
    - 5GMM cause value in REGISTRATION REJECT = #73 → UE sets 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes registration information, stores the PLMN identity in the forbidden PLMN list, enters state 5GMM-DEREGISTERED.PLMN-SEARCH
    - 5GMM cause value in REGISTRATION REJECT = #74 → UE sets the 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes registration information and the list of equivalent SNPNs (if available). The UE shall reset the registration attempt counter and store the SNPN identity in the "temporarily forbidden SNPNs" list.
    - 5GMM cause value in REGISTRATION REJECT = #75 → UE sets the 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes registration information and the list of equivalent SNPNs (if available). The UE shall reset the registration attempt counter and store the SNPN identity in the "permanently forbidden SNPNs" list.
    - 5GMM cause value in REGISTRATION REJECT = #76 → The UE shall set the 5GS update status to 5U3 ROAMING NOT ALLOWED and reset the registration attempt counter. If the 5GMM cause #76 is received from a CAG cell, and if the UE receives a "CAG information list" in the CAG information list IE or the Extended CAG information list IE included in the REGISTRATION REJECT message, the UE shall replace the "CAG information list" stored in the UE with the received CAG information list IE or the Extended CAG information list IE when received in the HPLMN or EHPLMN.
    - 5GMM cause value in REGISTRATION REJECT = #77 → UE sets 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes registration information, shall reset the registration attempt counter, shall enter the state 5GMM-DEREGISTERED
    - 5GMM cause value in REGISTRATION REJECT = #78 → UE sets the 5GS update status to 5U3 ROAMING NOT ALLOWED, deletes last visited registered TAI and TAI list. If the UE is not registering or has not registered to the same PLMN over non-3GPP access, the UE shall additionally delete the list of equivalent PLMNs, 5G-GUTI and ngKSI.
    - 5GMM cause value in REGISTRATION REJECT = #79 → UE aborts the initial registration procedure, sets the 5GS update status to 5U2 NOT UPDATED and enter state 5GMM-DEREGISTERED. ATTEMPTING-REGISTRATION or 5GMM-DEREGISTERED.PLMN-SEARCH.
    - 5GMM cause value in REGISTRATION REJECT = #80 → UE aborts the initial registration procedure, set the 5GS update status to 5U2 NOT UPDATED, enter state 5GMM-DEREGISTERED. PLMN-SEARCH and shall delete any 5G-GUTI, last visited registered TAI, TAI list and ngKSI.
    - 5GMM cause value in REGISTRATION REJECT = #81 → UE aborts the initial registration procedure, set the 5GS update status to 5U2 NOT UPDATED and enter state 5GMM-DEREGISTERED. ATTEMPTING-REGISTRATION or 5GMM-DEREGISTERED.PLMN-SEARCH.
    - 5GMM cause value in REGISTRATION REJECT = #82 → UE aborts the initial registration procedure, set the 5GS update status to 5U2 NOT UPDATED and enter state 5GMM-DEREGISTERED. ATTEMPTING-REGISTRATION or 5GMM-DEREGISTERED.PLMN-SEARCH.

- **State Transitions:**
    - Specific state transitions occur based on the 5GMM cause value, as described in the decision points and the specification.

- **Important Information Elements:**
    - 5GMM cause: Indicates the reason for the registration rejection.
    - T3346 value: Back-off timer value for congestion.
    - Rejected NSSAI: List of rejected S-NSSAIs, with rejection causes.
    - Extended rejected NSSAI: List of rejected S-NSSAIs, with rejection causes, when UE supports it.
    - Forbidden TAI(s) for the list of "5GS forbidden tracking areas for roaming" IE: List of TAIs where roaming is not allowed.
    - Forbidden TAI(s) for the list of "5GS forbidden tracking areas for regional provision of service" IE: List of TAIs where regional provision of service is not allowed.
    - RAT utilization control: Indicates the access technology of the NG-RAN cell on which the REGISTRATION REQUEST message was received is restricted
    - CAG information list: The "CAG information list" the UE should be using in the PLMN
    - Extended CAG information list: The "CAG information list" the UE should be using in the PLMN
    - N3IWF identifier IE: Information for a suitable N3IWF
    - TNAN information IE: Information for a suitable TNAN
