- **Procedure Name:** 5GMM Common Procedure Initiation During Registration
- **Triggering Conditions:**
    - The network needs to initiate 5GMM common procedures (identification, authentication, security procedures) during the registration procedure.
    - The initiation depends on the information received in the REGISTRATION REQUEST message.
    - Two NAS security mode control procedures are needed to signal an entire unciphered REGISTRATION REQUEST message followed by signaling of selected EPS NAS security algorithms.
    - Registration procedure with 5GS registration type IE set to "emergency registration" and the AMF is configured to support emergency registration for unauthenticated SUCIs.

- **Steps:**
    1. Network receives REGISTRATION REQUEST message.
    2. Network evaluates the REGISTRATION REQUEST message content.
    3. Network determines if identification procedure is needed.
    4. Network determines if authentication procedure is needed.
    5. Network determines if security mode control procedure is needed.
    6. If emergency registration with unauthenticated SUCI and AMF is configured to support it, the AMF may skip the authentication procedure and proceed directly to the security mode control procedure.
    7. Initiate the determined procedures as part of 5GMM common procedures of the ongoing registration procedure.
    8. If two NAS security mode control procedures are needed, initiate them as part of 5GMM common procedures of the ongoing registration procedure (see subclause 5.4.2.4).

- **Decision Points:**
    - Is identification required? → Yes / No
    - Is authentication required? → Yes / No
    - Is security mode control required? → Yes / No
    - Is it emergency registration with unauthenticated SUCI and AMF is configured to support it? → Yes / No

- **State Transitions:**
    - After step 1, the state is: Network received REGISTRATION REQUEST
    - After step 7, the state is: 5GMM common procedures initiated

- **Important Information Elements:**
    - REGISTRATION REQUEST: Contains information based on which the network decides which 5GMM common procedures to initiate.
    - 5GS registration type IE (within REGISTRATION REQUEST): Indicates the type of registration (e.g., emergency registration).
    - SUCI: Subscriber Concealed Identifier (impacts the authentication decision in case of emergency registration).
