📌 Your Workflow Summary
Your script automates the extraction of procedure flow information from 3GPP specification documents. The process follows these key steps:

1️⃣ Find the Section with Relevant Procedure Information
Query the SQLite database (sections table) to get all section names and IDs.
Use Gemini AI (LLM) to identify the section name that is most relevant to the procedure query.
✅ Output: A section name where the procedure is described.
2️⃣ Retrieve the Content of the Identified Section
Query the database (content table) using the found section name.
Extract and save the relevant content to a markdown file (gotsectioncontent.md).
✅ Output: The raw procedural text for further processing.
3️⃣ Extract the Procedure Flow as a Graph
Use Gemini AI to analyze the procedure content and generate a Flow Property Graph (FPG) in JSON format.
The JSON contains:
Nodes (States, Events, Actions)
Edges (Transitions between nodes)
Metadata (Message types, timestamps, etc.)
✅ Output: JSON representation of the procedure flow, saved as data.json.
4️⃣ Validate & Fix the JSON
Clean the JSON (removes unwanted formatting like ```json markdown syntax).
Validate JSON using Pydantic (GraphModel schema).
If valid: ✅ Proceed.
If invalid: ❌ Send error details to Gemini AI for automatic correction.
Save the corrected JSON back to data.json.
✅ Output: A fully validated and structured JSON representation of the procedure.
🔁 Final Outcome
A structured Flow Property Graph (FPG) in JSON format, representing the procedure flow.
Can be used for visualization, automation, or further analysis.
